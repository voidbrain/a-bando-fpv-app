# Editing the model

[← Guide](README.md)

## Look around in 3D

<video src="clips/look-3d.webm" controls muted loop width="720"></video>

- Switch to 3D to look around: drag to orbit, the wheel zooms.
- Back to 2D to edit the plan.

Shown as a tip over: `view-3d`.

## Select a building

<video src="clips/select.webm" controls muted loop width="720"></video>

- Click a building to select it: the inspector shows its size, floors, roof and openings.

Shown as a tip over: `tool-select`.

## Change a building

<video src="clips/adjust.webm" controls muted loop width="720"></video>

- Every value can be changed: here the wall height.
- Add a floor, take the roof off, make it a ruin: each change is one Undo step.

Shown as a tip over: `wall-height`.

## Draw a building

<video src="clips/add-building.webm" controls muted loop width="720"></video>

- Building tool: drag a rectangle on free ground. It snaps flush to close neighbours.

Shown as a tip over: `tool-building`.

## Plant trees with the brush

<video src="clips/trees.webm" controls muted loop width="720"></video>

- The tree brush plants trees along a stroke, or fills a square, a circle or a hand-drawn area.

Shown as a tip over: `tool-scatter`.

## Place a block from the Library

<video src="clips/library.webm" controls muted loop width="720"></video>

- The Library has ready-made objects, buildings and patterns, from the online catalogue and your own.
- Pick one, then click the map to place it.

Shown as a tip over: `library`.
